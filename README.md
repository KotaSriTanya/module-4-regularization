# Module 4 – Regularization

## Overview
This repository contains Python implementations of regularized cost functions and gradient calculations for linear regression and logistic regression using Jupyter Notebook.

## Objectives
- Understand the concept of regularization in machine learning.
- Implement the regularized cost function for linear regression.
- Implement the regularized cost function for logistic regression.
- Calculate gradients for regularized linear regression.
- Calculate gradients for regularized logistic regression.

## Topics Covered
1. Regularized Linear Regression Cost
2. Regularized Logistic Regression Cost
3. Gradient Calculation for Linear Regression
4. Gradient Calculation for Logistic Regression
5. L2 Regularization

## Technologies Used
- Python
- Jupyter Notebook
- NumPy
- Machine Learning

1. Clone or download this repository.
2. Open the `.ipynb` file using Jupyter Notebook or Google Colab.
3. Run the notebook cells sequentially.
4. Review the implementations and outputs.

## Learning Outcome
This exercise helps develop an understanding of how L2 regularization is added to cost functions and how it affects gradient calculations during model training.
